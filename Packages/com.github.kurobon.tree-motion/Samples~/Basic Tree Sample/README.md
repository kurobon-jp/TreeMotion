# Basic Tree Sample

Open `BasicTreeSample.unity` and enter Play mode.

This is the onboarding sample. It demonstrates only:

- Loading unordered API-style records with `LoadSnapshot`.
- Binding one reusable item prefab.
- Expanding and collapsing nested rows.
- Viewport pooling and animation through `TreeMotionScrollView`.

The sample controller contains no pooling, layout, RectTransform positioning, or animation code.
Click a group row to expand or collapse it. See the advanced TreeMotion Sample for structural
editing, nested group frames, item swaps, and diagnostics.
